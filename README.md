# Pranav Krishna Anand portfolio (v2)

Static site, no build step. Upload everything in this folder to the GitHub Pages repo root, except `ai-worker/`:
index.html, 404.html, .nojekyll, ai-config.js, Pranav-Krishna-Anand-Resume.pdf, runbook/, plugline/, loopline/, img/.

Live AI (the assistant, the Runbook and Playbook Agent, Plugline and Loopline) switches on with one line in `ai-config.js`. Follow ai-worker/SETUP.md. Until then the assistant answers from built-in Q&A and the demos say the live agent is not on yet.
