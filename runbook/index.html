Runbook and Playbook Agent

Turn your docs into a runbook in a minute.

Upload setup guides, release notes or incident notes. The agent reads them and writes an ordered procedure with owners, commands, checks and a rollback plan, and it flags what your docs leave out. I built the original at Opsera, where it cut turnaround from 1 to 1.5 days to under 15 minutes. This public version runs on an open model through Groq.
